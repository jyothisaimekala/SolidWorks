# SolidWorks Practice & Portfolio

A collection of 2D sketches and 3D models created while learning and practicing **SolidWorks**, covering everything from fundamental sketching to advanced part modeling and orthographic-to-3D conversions.

## About

This repository documents my hands-on practice with SolidWorks — building up from basic sketch geometry and simple parts toward more advanced modeling techniques like feature-based part design and converting orthographic (2D) engineering views into full 3D models. It's meant as both a personal record of progress and a showcase of my modeling skills.

## Repository Structure


| Folder | Description |
|---|---|
| `2D Sketches` | Practice sketches focused on geometry, constraints, and dimensioning — the building blocks for every 3D model. |
| `3D Models` | Finished 3D models generated from sketches, showing feature-based modeling in action. |
| `Ortho to 3D` | Exercises in reading orthographic projections (front, top, side views) and reconstructing them as accurate 3D parts. |
| `Part models` | Simpler individual part files, good for reviewing core modeling commands. |
| `Part models Advanced` | More advanced parts involving multiple features, complex geometry, and refined modeling techniques. |

## Tools & Software

- **SolidWorks** — 3D CAD modeling and 2D sketching
- File types: `.SLDPRT` (parts), `.SLDASM` (assemblies, if any), `.SLDDRW` (drawings, if any)

## Viewing the Files

SolidWorks files require SolidWorks or a compatible viewer to open. If you don't have SolidWorks installed, you can view most files using:

- [eDrawings Viewer](https://www.edrawingsviewer.com/) (free)
- [SolidWorks 3D ContentCentral Viewer](https://www.3dcontentcentral.com/)

## Skills Demonstrated

- 2D sketching with geometric relations and dimensional constraints
- Feature-based 3D part modeling (extrude, revolve, fillet, chamfer, etc.)
- Reading and interpreting orthographic engineering drawings
- Progressive modeling complexity, from basic parts to advanced multi-feature designs
